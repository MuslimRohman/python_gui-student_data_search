# Aplikasi Pencarian Data Mahasiswa Sains Data UNESA

**Pemrograman Dasar | Python | Graphical User Interface (GUI)**

## Deskripsi Proyek

Proyek ini bertujuan untuk mengembangkan aplikasi desktop berbasis **Python dan Tkinter** yang memudahkan pencarian informasi mahasiswa Program Studi Sains Data Universitas Negeri Surabaya.

Aplikasi menyediakan antarmuka grafis interaktif dengan fitur login, registrasi akun, dan pencarian data mahasiswa berdasarkan kata kunci.

## Tools & Libraries

- **Python** – Bahasa pemrograman utama.
- **Tkinter** – Pengembangan antarmuka grafis (GUI).
- **Messagebox** – Menampilkan pesan dan notifikasi.
- **AST** – Pengolahan struktur data Python.
- **Subprocess** – Menjalankan file program lain.

## Fitur Utama

1. **Login:** Autentikasi pengguna sebelum mengakses aplikasi.
2. **Registrasi Akun:** Pendaftaran akun untuk pengguna baru.
3. **Pencarian Mahasiswa:** Pencarian informasi berdasarkan nama atau NIM.
4. **Tampilan Data:** Menampilkan nama, NIM, jenis kelamin, dan status keaktifan mahasiswa.
5. **GUI Interaktif:** Antarmuka dengan kolom pencarian, tabel hasil, dan scrollbar.

## Hasil Implementasi

- Mengembangkan aplikasi desktop menggunakan Python dan Tkinter.
- Mengimplementasikan fitur login dan registrasi pengguna.
- Menyediakan pencarian dan penampilan informasi mahasiswa melalui tabel interaktif.
- Mengintegrasikan beberapa file Python dalam satu alur aplikasi.

## Struktur Repository

- `Program.py` — Program utama aplikasi pencarian data mahasiswa.
- `login1.py` — Implementasi antarmuka login dan registrasi pengguna.
- `login1.png` — Aset gambar antarmuka login.

- `README.md` — Dokumentasi repository.
